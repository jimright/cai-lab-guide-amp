# Module 1: Setup

Before starting the exercise in Module 2, make sure your environment is ready:

1. Open a Workbench session for this project.
2. Verify your Python version.
3. Confirm you can see the project's files in the Workbench file browser.

Try running this in a terminal:

```bash
python3 --version
```

Once that works, move on to [Module 2: Exercise](module-2-exercise.md).
