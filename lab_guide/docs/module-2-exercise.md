# Module 2: Exercise

## Try it yourself

Given the inputs below, compute the output.

| Input | Output |
| ----- | ------ |
| 2     | 4      |
| 3     | 9      |
| 4     | ?      |

<details>
<summary>Solution</summary>

The pattern is `output = input * input`, so for an input of `4` the output
is `16`.

</details>
