# Lab Guide AMP — Example Hands-on Lab

Welcome! This is the demo content shipped with the Lab Guide AMP. It exists
to prove that the build pipeline works end-to-end with both supported
engines (MkDocs and Zensical) — swap it out for your own course material.

## What you'll do

- [Module 1: Setup](module-1-setup.md) — get your environment ready.
- [Module 2: Exercise](module-2-exercise.md) — try a short hands-on exercise.

!!! note
    This page is generated by whichever engine is set in `GUIDE_ENGINE`
    (`mkdocs` or `zensical`). Both read the same markdown in `docs/`.
